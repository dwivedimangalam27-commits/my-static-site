# Web Design Experiment 1

## Project Overview
This project is a simple static website created as part of the Web Design Lab. It demonstrates how to create a GitHub repository, work with branches, merge changes, and host a website using GitHub Pages.

## Technologies Used
- HTML5
- CSS3
- Git and GitHub
- GitHub Pages

## Project Features
- Simple and responsive webpage structure
- Navigation links for Home, About, and Contact
- Student information section
- Information about GitHub and GitHub Pages
- Footer with student details
- Website hosting through GitHub Pages

## Project Structure
```text
Web-Design-Experiment-1/
│
├── index.html
├── style.css
└── README.md
```

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Make sure `style.css` is in the same folder so the webpage styling works correctly.

## GitHub Branching and Merging
The project can be managed using Git branches.

1. Create a new branch for making changes.
2. Edit the HTML or CSS files.
3. Commit the changes.
4. Merge the branch into the `main` branch.
5. Push the updated project to GitHub.

## Hosting with GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Select the `main` branch and the root folder as the publishing source.
4. Click **Save**.
5. Wait for GitHub Pages to publish the website.
